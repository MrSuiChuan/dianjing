## 二、分类标题模板(变量用 {} 标出,可直接套)

### ① 玩梗/创意实验/体验揭秘型

- `我用{工具}做了一部《{超级IP}》的{产物}…`
- `当我把{N}{内容}喂给 AI — 坏了,我成{X}了?`
- `{平台}把我的{资产}变成了一个巨大的"{比喻}"。`
- `{热点事件}到底能不能做出来?我的答案是:当然能。`
- `我潜伏进了"{诱惑标签}"的{场景},发现了一些灰色的秘密`
- `我只让{模型}回复{极小动作},它就把我整个{资产}都偷走了`
- `给{角色}打工了一天,我们体验上了 AI 时代最魔幻的工作`
- 结构:[具象化操作 / 体验冒险] + [差一点的反差 / 自问自答 / 灰色揭秘]

### ② 测评/横评/首发观点型

- `通俗易懂揭秘{新品},{碾压动词}{旧品1}与{旧品2}` (碾压动词:降维打击/秒杀)
- `一手实测{新品} — {品类}的 ChatGPT 时刻到来了。`
- `{N}个动作,给{人群}准备的{品类}评测` (查资料、劝老板、写周报)
- `用{工具}还原{超级IP}`
- `我花了{N}个小时,做了一个可能更{形容词}的{产物}`
- `体验完{新品}以后,我觉得这就是{品类}有史以来最大的{判断}`
- `{厂牌}偷偷在{产品}中植入了{操作},只为{目的}。`
- `AI 说不出的{X},成了鉴别{品类}最好的照妖镜。`
- 结构:[权威动作:揭秘/一手实测/还原/体验] + [对比碾压 or 极致定调]

### ③ 工具实操/教学型

- `从 0 到 1 带你速通{X}。`
- `从零开始,教你用{工具}搓出属于你自己的第一个{产物}`

- `全网最详细的{工具}入门教程,手把手教你玩转{X}`
- `不会{门槛技能}也能{帅气结果},这是一份从 0 开始的{X}保姆…`
- `每天{动作}{时长}后,这是我觉得现在最好用的{X}…`
- `分享{N}个{场景}必备的超实用 Prompt`
- `分享一个我用了{N年}的{X},半小时帮你搞定{Y}`
- `我把{顶级资源},做成了{产物}来帮我{目的}`
- 结构:[起点/门槛降低] + [动作动词:速通/搓/上手/手把手] + [带数量的具体产出]

### ④ 开源/分享型(招牌)

- `今天,我决定把{X}开源了。`

- 结构:[代价/动作] + [我 + 开源/分享] + [高价值物]

### ⑤ 思考/认知/心得型

- `{副词}实用的{X},帮你挖出最本质的答案。` (极度/超级/真正)
- `说一个反常识的真相,{X}`
- `作为{身份},我劝你先别急着用{X}` (反向劝退)

- `让 AI"{效果}"的尽头,居然是{反差物}` (居然是型)
- `{X}里最大的 Bug,也是{大词}最伟大的起点` (反转金句型)
- `AI 用得好不好,跟你会不会{人的能力},我觉得越来越是同一件事。`
- 结构:[时间锚/反预期] + [个人判断 / 反转金句]

## 三、该博主标题风格 DNA(7 条)

1. **第一人称口语**:大量"我/你/还是想/说一个/聊聊/真觉得"——像聊天。
2. **数字优先真实**:优先用素材里的真实数字,没有就补可替换的修辞数字并标注"待替换"(10级/12个/16小时/20亿/100篇/54个/49块9…)。
3. **具象动作动词**:搓/喂/还原/速通/拆解/降维打击/揭秘/挖出/潜伏/偷/蒸馏。
4. **代价/反差/反预期前置**:浪费20亿Token后/坏了我成数字生命了/我劝你先别急着用AI/说一个反常识的真相/再见了ChatGPT。
5. **标题=可独立传播金句**:"我成数字生命了?""帮你挖出最本质的答案""AI视频的ChatGPT时刻到来了""AI里最大的Bug,也是人类文明最伟大的起点"。
6. **个人判断定调句式**:"这是我觉得现在最好用的…""我答案是:当然能""我觉得这就是…有史以来最大的…"。
7. **反差 / 反转结构**:用"居然是""反而""也是…的起点"制造认知落差。

你的垂类是「AI 工程提效 & Agent 落地」给开发者。把 5 类公式的变量换成你的世界:

- {工具}→ Cursor / Claude Code / Codex / 通义
