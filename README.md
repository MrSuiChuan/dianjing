# 画龙点睛 · dianjing

一句话选题 → 10 条可独立传播的爆款标题（公众号 / 知乎 / 小红书 / B 站推文）。

## 结构

- `SKILL.md` — 主指令：触发条件、平台适配、5 类公式定位、自检与发布后回填
- `references/title_formulas.md` — 5 类公式 + 高赞 10 式 + 风格 DNA + 样本 + 生成 Prompt
- `references/title_index.md` — 610 条爆款标题纯列表（去重，按原时间倒序）
- `agents/openai.yaml` — UI 元数据（display_name 等，可选）

## 使用

把一句话选题发给它即可，会自动触发；也可以显式调用 `$dianjing`。建议附上平台与目标，标题会更贴场景：

> 帮我想 10 个标题。我写了篇文章，讲好标题根本不靠灵感，是我把 621 篇爆款标题逆向成 5 套公式做成的 Skill。发公众号，目标是涨粉，读者是做内容和写代码的人。

它会把平台、目标、读者拆开处理，按公众号的字数上限和红线来压标题。

输出：5 类公式各 2 条，共 10 条标题，每条标注公式类型与钩子解读；末尾附 Top 3 推荐和缺素材清单。

```text
# 标题                                      公式类型    钩子解读
1 我把 621 篇爆款标题拆了，发现根本没有玄学        ①玩梗体验    621 拆解反差
2 说一个反常识的真相，好标题根本不靠灵感          ⑤思考心得    反常识金句
3 今天，我决定把这套标题公式开源了               ④开源分享    开源招牌
...
```

小提示：

- 数字优先用正文里的真实数字；修辞数字会标【待替换】，发布前记得替换核实
- 说"换一批"会用没用过的公式重产；说"只要某一类"会专攻该类多给几条
- 非 AI 垂类（美食、育儿等）同样适用——公式是结构，换领域词即可

## 安装

- 仓库地址：https://github.com/MrSuiChuan/dianjing
- 克隆/拷贝本仓库到 `~/.codex/skills/dianjing/`（或 `$CODEX_HOME/skills/dianjing/`）
- 需要 `.skill` 分发包时，用 skill-creator 的打包流程手动生成即可（`dist/` 不入库）

> 公式模板逆向自某 AIGC 顶流博主 621 篇爆款标题，仅供个人学习与自用。这是风格模板，不是爆款保证——平台权重和账号信任决定传播下限，标题决定上限。
