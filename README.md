# 画龙点睛 · dianjing

把一个选题一句话,变成 10 条可独立传播的标题(公众号 / 知乎 / 小红书 / B 站内容)。核心价值:让标题本身就是一句可转发的金句,而不是干瘪的"浅谈/解析"。

先说清它做不到什么:**标题的字数、有没有数字、用不用问号,和最终点赞几乎没有相关性**(实测最高 0.09)。这个 skill 不承诺流量,它保证的是三件事:说清具体的事、带明确立场、不和已有标题撞车。

## 结构

- `SKILL.md` — 主指令:触发条件、6 类公式速查、8 条风格 DNA、生成流程与自检
- `references/title_formulas.md` — 6 类公式 + 高赞爆款公式 + 样本标题 + 生成 Prompt(每次生成必读)
- `references/title_index.md` — 标题索引(去重 610 条,按原时间倒序),需要核对真实措辞时按需检索
- `scripts/title_overlap_check.py` — 标题查重(连续重合 ≥10 字判不合格)
- `agents/openai.yaml` — UI 元数据(display_name 等,可选)

## 使用

把一句话选题发给它即可自动触发;也可以显式调用 `$dianjing`。建议附上垂类与目标读者,标题会更贴场景:

> 帮我想 10 个标题。我写了篇文章,主旨是介绍我这个生成爆款标题的 dianjing Skill。垂类:AI;目标读者:内容创作者

输出:10 条标题,覆盖 6 类(⑥批判冲突金句至少 2 条,其余每类至少 1 条),每条标注公式类型与钩子解读;末尾附 Top 3 推荐和查重结果。

```text
# 标题                                      公式类型    钩子解读
1 我只加了 1 个文件,AI 就再没写崩过团队代码风格        ①玩梗体验    1 个文件的反差
2 一手实测 Cursor 规则文件 — AI 按你风格写的 ChatGPT 时刻  ②测评首发  一手实测定调
3 从 0 到 1 带你速通 Cursor 规则文件。              ③工具实操    速通+明确产物
```

小提示:

- 数字只负责具体化,不是加分项;别编离谱的(如"浪费 9999 亿")
- 说"换一批"会用没用过的公式重产;说"只要某一类"会专攻该类多给几条
- 非 AI 垂类(美食、育儿等)同样适用——公式是结构,换领域词即可
- 交付前跑一遍 `scripts/title_overlap_check.py`,和索引里已有的标题撞车就重写

## 安装

- 仓库地址:https://github.com/MrSuiChuan/dianjing
- 克隆/拷贝本仓库到 `~/.codex/skills/dianjing/`(或 `$CODEX_HOME/skills/dianjing/`)
- 需要 `.skill` 分发包时,用 skill-creator 的打包流程手动生成即可(`dist/` 不入库)

> 公式提炼自 610 条真实标题 + 442 篇带赞数样本的逆向分析,仅供个人学习与自用。这是风格模板,不是爆款保证——平台权重、话题热度和发布时间决定传播下限,标题只影响被点开的概率。
